## 5. Detailed Interface Specifications

### 5.1 Enumerations & Data Structures

#### 1. `ImageSourceKind` (Enum)
Represents the exact channel through which an invoice/payment image entered SingWallet:
- `systemShare` (Value: 0): System share sheet (`ACTION_SEND` on Android, Share Extension on iOS).
- `photoPicker` (Value: 1): In-app photo picker (`PHPickerViewController` on iOS, `PickVisualMedia` on Android).
- `shortcutsAction` (Value: 2): Siri Shortcuts / App Intents / Back Tap / Action Button / Android App Shortcut.
- `clipboard` (Value: 3): User explicit paste from system clipboard.
- `quickSettingsTile` (Value: 4): Android Quick Settings Tile single-frame capture (P1 feature; iOS unsupported but enum aligned).

#### 2. `CaptureResult` (Data Class)
Encapsulates metadata for an ingested image. Raw image bytes are **never** passed across the channel:
- `captureId` (String): Unique task ID (format: `cap_{sha256[:16]}_{epoch_ms}`).
- `localFilePath` (String): Private storage relative or absolute sandbox path.
- `imageWidth` (int): Decoded image width in physical pixels.
- `imageHeight` (int): Decoded image height in physical pixels.
- `contentHash` (String): SHA-256 hexadecimal digest of original image data.
- `sourceKind` (ImageSourceKind): Ingestion origin channel.

#### 3. `OcrBoundingBox` (Data Class)
Geometric rectangle bounding a recognized text unit.
- `left` (double): Horizontal normalized offset `[0.0, 1.0]`, origin at **top-left corner**.
- `top` (double): Vertical normalized offset `[0.0, 1.0]`, origin at **top-left corner**.
- `width` (double): Normalized box width `[0.0, 1.0]`.
- `height` (double): Normalized box height `[0.0, 1.0]`.

#### 4. `OcrTextLine` (Data Class)
A single horizontal line of recognized text:
- `text` (String): Extracted text content.
- `boundingBox` (OcrBoundingBox): Normalized coordinates.
- `confidence` (double?): Confidence score in range `[0.0, 1.0]`. Nullable when the underlying engine does not provide confidence.

#### 5. `OcrDocument` (Data Class)
Complete structured OCR result for an ingested screenshot:
- `captureId` (String): Matches the originating `CaptureResult.captureId`.
- `lines` (List<OcrTextLine>): Ordered collection of recognized text lines.
- `engineIdentifier` (String): Descriptive string (e.g. `"MLKit_Android_v2"` or `"AppleVision_iOS_17"`).
- `processTimeMs` (int): Execution duration in milliseconds.

## 6. Dual-Platform Native Bridge Architecture

### 6.1 Android (Kotlin) Host Architecture

1. **Package and Generated Files**:
   - Package: `com.singwallet.app.bridge`
   - Generated File: `android/app/src/main/kotlin/com/singwallet/app/bridge/NativeBridge.g.kt`
2. **Registration in `MainActivity.kt`**:
   ```kotlin
   package com.singwallet.app

   import io.flutter.embedding.android.FlutterActivity
   import io.flutter.embedding.engine.FlutterEngine
   import com.singwallet.app.bridge.NativeCaptureHostApi
   import com.singwallet.app.bridge.NativeCaptureHostApiImpl

   class MainActivity: FlutterActivity() {
       override fun configureFlutterEngine(flutterEngine: FlutterEngine) {
           super.configureFlutterEngine(flutterEngine)
           val hostApi = NativeCaptureHostApiImpl(applicationContext, flutterEngine.dartExecutor.binaryMessenger)
           NativeCaptureHostApi.setUp(flutterEngine.dartExecutor.binaryMessenger, hostApi)
       }
   }
   ```
3. **ML Kit Coordinate Normalization**:
   - ML Kit `boundingBox` is in absolute physical integer pixels with top-left origin.
   - Normalization formula:
     ```kotlin
     val rect = textLine.boundingBox ?: Rect()
     val flutterLeft = (rect.left.toDouble() / imageWidth).coerceIn(0.0, 1.0)
     val flutterTop = (rect.top.toDouble() / imageHeight).coerceIn(0.0, 1.0)
     val flutterWidth = (rect.width().toDouble() / imageWidth).coerceIn(0.0, 1.0)
     val flutterHeight = (rect.height().toDouble() / imageHeight).coerceIn(0.0, 1.0)
     ```
4. **16 KB Memory Page Size Compatibility**:
   - Android 15+ devices support 16 KB memory page sizes. Native libraries (`.so` from Flutter engine, SQLCipher, ML Kit) must be ELF-aligned to 16 KB boundaries.

### 6.2 iOS (Swift) Host Architecture

1. **Target and Generated Files**:
   - Target: `Runner`
   - Generated File: `ios/Runner/Plugins/NativeBridge.g.swift`
2. **Registration in `AppDelegate.swift`**:
   ```swift
   import Flutter
   import UIKit

   @main
   @objc class AppDelegate: FlutterAppDelegate {
       override func application(
           _ application: UIApplication,
           didFinishLaunchingWithOptions launchOptions: [UIApplication.LaunchOptionsKey: Any]?
       ) -> Bool {
           let controller = window?.rootViewController as! FlutterViewController
           let hostApi = NativeCaptureHostApiImpl(controller: controller)
           NativeCaptureHostApiSetup.setUp(binaryMessenger: controller.binaryMessenger, api: hostApi)
           GeneratedPluginRegistrant.register(with: self)
           return super.application(application, didFinishLaunchingWithOptions: launchOptions)
       }
   }
   ```
3. **Apple Vision Coordinate Inversion**:
   - Vision `VNRecognizeTextRequest` produces normalized bounding boxes with origin at the **bottom-left corner** (`origin.y` increases upwards).
   - Standard conversion to top-left origin:
     ```swift
     let visionBox = observation.boundingBox
     let flutterLeft = visionBox.origin.x
     let flutterTop = 1.0 - visionBox.origin.y - visionBox.size.height
     let flutterWidth = visionBox.size.width
     let flutterHeight = visionBox.size.height
     ```
4. **Share Extension Memory Guard (<120MB Jetsam)**:
   - Share Extension runs in an independent extension process.
   - Under no circumstances may the Flutter engine or Vision OCR be initialized inside the Share Extension.
   - The Share Extension performs streaming disk writes directly to `group.com.singwallet.app/PendingCaptures/` and writes `pending_manifest.json` via `NSFileCoordinator`.

## 9. Edge Cases & Boundary Behaviors

| # | Feature | Input / Condition | Observed & Specified Behavior |
|---|---------|-------------------|-------------------------------|
| 1 | `recognizeCapture` | Invalid or Non-existent `captureId` | Native layer attempts to resolve file; fails to find file; must throw structured `PlatformException("FILE_NOT_FOUND", "Capture image not found for id: $captureId", null)` instead of crashing native process. |
| 2 | `recognizeCapture` | Zero or Negative Image Dimensions (`width <= 0` or `height <= 0`) | Native adapter must validate dimensions prior to division; prevents `DivideByZeroException` or NaN coordinates. Return empty document or throw error. |
| 3 | `OcrBoundingBox` | Coordinate Out of `[0.0, 1.0]` Boundary | Android ML Kit or Vision may occasionally output bounding rects slightly beyond image bounds; native adapter must apply `.coerceIn(0.0, 1.0)` / `max(0.0, min(1.0, val))` to protect downstream rule calculations. |
| 4 | `OcrBoundingBox` | Apple Vision Coordinate Inversion | Apple Vision Y axis origin is bottom-left. Without `1.0 - visionBox.origin.y - visionBox.size.height`, coordinates are vertically flipped, corrupting OCR evidence highlighting in Flutter UI. |
| 5 | `startOneShotScreenCapture` | Invocation on iOS Platform | iOS sandboxing completely prohibits third-party screen capture APIs. Native Swift host returns `nil` (or throws `PlatformException("UNSUPPORTED")`), Dart layer handles null gracefully without crash. |
| 6 | `startOneShotScreenCapture` | User Denies MediaProjection Prompt on Android | Android system cancels projection request; HostApi returns `null` to Dart, UI remains on current page without error dialog. |
| 7 | `readImageFromClipboard` | Clipboard Contains Text, URL, or Empty | HostApi checks MIME type / clip data representation; if not image, returns `null` immediately. No file is created. |
| 8 | `getOrCreateDatabaseKey` | Device Reboots & Is Locked Before First Unlock | Android Keystore / iOS Keychain items with `kSecAttrAccessibleAfterFirstUnlockThisDeviceOnly` are inaccessible until first user unlock; API returns error until device unlocked. |
| 9 | `pickSingleImage` | User Selects Multiple Images or Cancels | System picker returns empty selection on cancel (returns `null`); picker is strictly configured for single image (`limit: 1`). |
| 10 | `NativeCaptureFlutterApi` | App Killed / Cold Start via Share Intent | `onExternalCaptureReceived` cannot be received because Flutter engine is not yet initialized. System falls back to cold-start intent processing; on launch, Flutter calls `fetchPendingExternalCaptures()` to pick up the task. |
| 11 | `pigeons/native_bridge.dart` | `Uint8List` Missing `import 'dart:typed_data';` | `dart analyze` reports `Undefined name 'Uint8List'`. Must explicitly include `import 'dart:typed_data';` in `pigeons/native_bridge.dart` when configuring project. |
| 12 | Share Extension (iOS) | Memory Exceeds 120 MB Jetsam Limit | Extension process terminates immediately (`EXC_RESOURCE RESOURCE_TYPE_MEMORY`). Specification mandates zero bitmap decoding in extension: write raw file stream directly to App Group container without `UIImage(data:)`. |

## 10. Architectural Guardrails & Static Analysis Checklist

To achieve acceptance criteria for M0:

1. **Zero Raw Bytes over Platform Channels**:
   - High-resolution payment screenshots (often 4K, 5–15 MB uncompressed bitmap) must **never** be passed across Pigeon channels as raw byte buffers (`Uint8List`).
   - Only file system paths (`localFilePath`) and IDs (`captureId`) are passed.
2. **Deterministic Code Generation**:
   - `dart run pigeon --input pigeons/native_bridge.dart` must run with exit code 0.
   - All 4 target files must be regenerated without manual modifications.
3. **Flutter Static Analysis**:
   - `flutter analyze` must report zero errors and zero warnings on all generated and handwritten Dart files.
4. **Android Native Compilation**:
   - Minimum SDK: API 29 (Android 10).
   - Target SDK: API 34.
   - Kotlin version: 1.9+ / 2.0+.
   - 16 KB memory page size alignment verified for native libraries.

   - Minimum iOS deployment target: iOS 16.0 (required for Apple Vision Chinese OCR without external models).
   - Swift version: Swift 5.9+.
   - App Groups: `group.com.singwallet.app` entitlement configured.
